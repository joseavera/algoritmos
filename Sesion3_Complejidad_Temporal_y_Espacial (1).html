La idea en dos minutos

Todo programa gasta dos cosas

Piensa en preparar tacos para una fiesta: te importa cuánto tardas y cuánto espacio ocupas en la cocina. Los programas también gastan dos recursos:

Complejidad temporal Los pasos

¿Cuántas veces trabaja el programa? Lo mediremos con un contador.

Complejidad espacial Las casillas

¿Cuántos datos guarda? Cada variable es 1 casilla; una lista de 10 datos son 10 casillas.

Hoy no vas a memorizar fórmulas: vas a ejecutar, observar y concluir. Cada ejercicio tiene tres momentos: predice, ejecuta y comprueba.

Un ciclo: el contador sigue a n

Este programa repite un trabajo n veces y cuenta cuántas veces lo hizo. Predice: si n = 5, ¿cuánto crees que marcará el contador?

Un ciclo que se repite n veces hace n pasos: si n se duplica, los pasos se duplican. Eso es crecimiento lineal, O(n).

Consejo de Mixtle

Truco rápido: si al duplicar n el contador se duplica, es O(n); si se cuadruplica, es O(n²). No necesitas leer el código: ¡basta con medir!

Ahora, la memoria Ejercicio 4

¿Cuántas casillas usa cada programa?

Los dos programas suman 5 números. Uno los suma sobre la marcha; el otro primero los guarda todos en una lista. Para contar casillas recuerda: cada variable = 1 casilla y una lista de 5 = 5 casillas.

Programa A: SumaSinGuardar
Proceso SumaSinGuardar
    Definir i Como Entero;
    Definir numero, suma Como Real;
    suma <- 0;
    Para i <- 1 Hasta 5 Hacer
        Escribir "Escribe un número:";
        Leer numero;
        suma <- suma + numero;
    FinPara
    Escribir "La suma es: ", suma;
FinProceso
Programa B: SumaGuardando
Proceso SumaGuardando
    Dimension datos[5];
    Definir i Como Entero;
    Definir suma Como Real;
    suma <- 0;
    Para i <- 1 Hasta 5 Hacer
        Escribir "Escribe un número:";
        Leer datos[i];
    FinPara
    Para i <- 1 Hasta 5 Hacer
        suma <- suma + datos[i];
    FinPara
    Escribir "La suma es: ", suma;
FinProceso

Ejecuta los dos y comprueba que dan la misma suma. Luego completa el conteo de casillas. (Pista: en el programa A las casillas son i, numero y suma; en el B son i, suma y las de la lista datos.)

El programa A siempre usa 3 casillas, sin importar cuántos números sume: memoria O(1). El B guarda cada número, así que su memoria crece con n: O(n). Los dos tardan lo mismo (O(n)), pero no gastan la misma memoria.

Consejo de Mixtle

Para analizar la memoria, pregúntate: "¿estoy guardando algo que crece con n?" Si solo hay variables sueltas, la memoria es O(1). Si guardas una lista de n datos, es O(n).

Reglas que te llevas

Tiempo: ciclos seguidos se suman; ciclos anidados se multiplican; los números que acompañan se descartan.

Memoria: variables sueltas son O(1); una lista de n datos es O(n).

Pon a prueba lo aprendido

Preguntas rápidas

1. Un programa hace 5n + 2 pasos. ¿Cuál es su orden de tiempo?
O(n). El 5 y el 2 se descartan y queda solo n.
2. Un programa copia una lista de n nombres a otra lista nueva. ¿Cuánta memoria extra usa?
O(n), porque crea n casillas nuevas.
3. ¿Un programa rápido siempre usa poca memoria?
No. A veces se guardan datos extra para ahorrar pasos, como memorizar las tablas de multiplicar. Rapidez y memoria hay que equilibrarlas.
Cierre de la sesión

Conclusión

Hoy comprobaste con tus propias ejecuciones que los programas gastan dos recursos: tiempo y memoria. Con un contador viste que un ciclo da n pasos (O(n)), que un ciclo dentro de otro da n × n (O(n²)) y que dos ciclos seguidos suman y siguen siendo O(n). Con las casillas viste que guardar una lista de n datos hace crecer la memoria, mientras que las variables sueltas no. En la Sesión 4 estudiaremos el Tema 1.4: casos mejor, promedio y peor, para responder otra pregunta: ¿un mismo programa siempre tarda lo mismo?
