Herramienta de trabajo

¿Qué es PSeInt y por qué lo usamos?

PSeInt es un entorno gratuito para escribir y ejecutar pseudocódigo en español. Te deja concentrarte en la lógica del algoritmo —las mismas propiedades que estudiamos en la Sesión 1— sin preocuparte todavía por la sintaxis de C# u otro lenguaje. Lo que escribas aquí es, literalmente, el algoritmo antes de convertirse en programa.

Sintaxis mínima que usarás hoy
Proceso ... FinProcesodelimita el algoritmo completo
Definir x Como Enterodeclara una variable
Leer x / Escribir xentrada y salida
Para i <- 1 Hasta n Hacer ... FinParaciclo controlado por contador
Mientras cond Hacer ... FinMientrasciclo controlado por condición
Si cond Entonces ... SiNo ... FinSidecisión

Cómo trabajar hoy. Descarga PSeInt (gratuito) desde su sitio oficial, pega cada algoritmo de este taller en el editor, presiona Ejecutar (F5) y prueba con distintos valores de entrada. No necesitas escribir código desde cero: hoy vas a correr, medir y clasificar.

Ejercicio guiado

1 · Un algoritmo que ya diseñaste

En la Sesión 1 diseñaste en papel el algoritmo para promediar tres calificaciones. Aquí está, aterrizado en PSeInt. Ejecútalo y verifica que el resultado coincide con lo que calculaste a mano.

PromedioCalificaciones O(1)
Proceso PromedioCalificaciones
    Definir cal1, cal2, cal3, suma, promedio Como Real;

    Escribir "Ingresa la primera calificación:";
    Leer cal1;
    Escribir "Ingresa la segunda calificación:";
    Leer cal2;
    Escribir "Ingresa la tercera calificación:";
    Leer cal3;

    suma <- cal1 + cal2 + cal3;
    promedio <- suma / 3;

    Escribir "El promedio es: ", promedio;
FinProceso
Sin ciclos: el número de pasos no cambia sin importar los valores capturados.
Ejercicio guiado

2 · Contando operaciones con un ciclo

Estos dos programas hacen exactamente lo que viste en la Sesión 2: uno recorre una lista una vez, el otro la recorre contra sí misma. Ambos llevan un contador que se incrementa cada vez que se ejecuta el trabajo real, para que el crecimiento deje de ser teoría y lo veas imprimido en pantalla.

ContadorLineal O(n)
Proceso ContadorLineal
    Definir n, i, contador Como Entero;

    Escribir "¿Cuántos elementos tiene tu lista?";
    Leer n;
    contador <- 0;

    Para i <- 1 Hasta n Con Paso 1 Hacer
        contador <- contador + 1;
    FinPara

    Escribir "Operaciones realizadas: ", contador;
FinProceso
1 ciclo → el contador termina exactamente en n.
ContadorCuadratico O(n²)
Proceso ContadorCuadratico
    Definir n, i, j, contador Como Entero;

    Escribir "¿Cuántos elementos tiene tu lista?";
    Leer n;
    contador <- 0;

    Para i <- 1 Hasta n Con Paso 1 Hacer
        Para j <- 1 Hasta n Con Paso 1 Hacer
            contador <- contador + 1;
        FinPara
    FinPara

    Escribir "Operaciones realizadas: ", contador;
FinProceso
Ciclo anidado → el contador termina exactamente en n × n.

Ejecuta cada uno con n = 5, luego con n = 10 y luego con n = 20. Anota el valor final del contador en la hoja de registro más abajo.

3 · Clasifica un algoritmo nuevo

Este algoritmo busca un número dentro de una lista de 10 valores, deteniéndose en cuanto lo encuentra. Ejecútalo varias veces buscando números distintos (algunos al principio de la lista, otros al final o que no existan) y observa cómo cambia el contador.

BusquedaLineal ¿O(?) — complétalo tú
Proceso BusquedaLineal
	
    Definir lista Como Entero;
    Dimension lista[10];
	
    Definir i, buscado, contador Como Entero;
    Definir encontrado Como Logico;
	
    // Llenar la lista
    Para i <- 0 Hasta 9 Con Paso 1 Hacer
        lista[i] <- (i + 1) * 3;
    FinPara
	
    Escribir "¿Qué número buscas?";
    Leer buscado;
	
    contador <- 5;
    encontrado <- Falso;
    i <- 0;
	
    // Búsqueda lineal
    Mientras i <= 9 Y encontrado = Falso Hacer
		
        contador <- contador + 1;
		
        Si lista[i] = buscado Entonces
            encontrado <- Verdadero;
        FinSi
		
        i <- i + 1;
		
    FinMientras
	
    Si encontrado Entonces
        Escribir "Encontrado. Operaciones usadas: ", contador;
    SiNo
        Escribir "No encontrado. Operaciones usadas: ", contador;
    FinSi
	
FinProceso
Pista: compara el contador cuando el número está en la posición 1 contra cuando no existe en la lista. ¿Qué caso de la Sesión 2 es cada uno?

Consejo de Mixtle

Un contador que se incrementa dentro del ciclo es la forma más honesta de "ver" la complejidad de un algoritmo: no estás adivinando ni memorizando fórmulas, estás contando exactamente lo que la computadora hizo. Si duplicas n y el contador se duplica, sospecha de O(n). Si se cuadruplica, sospecha de O(n²). Esa intuición te va a acompañar el resto del cuatrimestre.

Conclusión

Escribir un algoritmo en PSeInt y agregarle un contador de operaciones convierte la notación Big-O de una fórmula abstracta en un número que ves crecer en pantalla. Al comparar el comportamiento de ContadorLineal, ContadorCuadratico y BusquedaLineal frente a distintos valores de n, practicaste exactamente lo que exige el problemario técnico de la Unidad 1: calcular y demostrar la complejidad temporal de un código real, no solo citarla de memoria. Guarda tu hoja de registro: es la base directa de esa entrega.
