Abrir PSeInt Web

La forma de todo programa

Todo programa en PSeInt empieza con Proceso y un nombre, y termina con FinProceso. Entre esas dos palabras va lo que quieres que haga, una instrucción por línea, y casi todas terminan con ;

Si te equivocas, no pasa nada. PSeInt te avisa dónde está el error. Lee el mensaje, revisa esa línea y corrige. Equivocarse y corregir es parte de programar.

Ejercicio 2

Variables y la flecha

Qué aprenderás: guardar un dato en una variable con la flecha <-.

Analogía

Una variable es una cajita con etiqueta. La etiqueta es el nombre (edad) y dentro guardas un valor. La flecha <- significa "mete el valor de la derecha en la caja de la izquierda".

MiEdad Escríbelo tú
Proceso MiEdad
    Definir edad Como Entero;
    edad <- 18;
    Escribir "Tengo ", edad, " años";
    edad <- edad + 1;
    Escribir "El próximo año tendré ", edad, " años";
FinProceso
Lo que debe aparecer en la consolaTengo 18 años El próximo año tendré 19 años

Pruébalo: cambia el 18 por tu edad y ejecuta de nuevo.

La flecha <- sirve para:

Primero la caja edad guarda 18. Luego edad + 1 se calcula (19) y se vuelve a guardar en la misma caja. Una variable puede cambiar de valor; por eso se llama variable.

Ejercicio 5

Tomar decisiones

Qué aprenderás: hacer que el programa elija entre dos caminos con Si … Entonces … SiNo … FinSi.

MayorDeEdad Escríbelo tú
Proceso MayorDeEdad
    Definir edad Como Entero;
    Escribir "¿Cuántos años tienes?";
    Leer edad;
    Si edad >= 18 Entonces
        Escribir "Eres mayor de edad";
    SiNo
        Escribir "Eres menor de edad";
    FinSi
FinProceso

Predice y luego ejecuta con cada edad. ¿Qué mensaje aparece?

Edad que escribesMensaje
17
18
25

Experimenta: cambia >= por > y ejecuta de nuevo con 18.

Con > y edad 18, el mensaje es:

>= significa "mayor o igual", así que 18 sí cuenta como mayor de edad. Con > solo cuentan los que son estrictamente mayores que 18. Un solo símbolo cambia el resultado: por eso hay que escribirlos con cuidado.

Ejercicio 6

Repetir con un ciclo

Qué aprenderás: repetir instrucciones con Para … Hasta … Hacer … FinPara. Este es el primer paso para contar pasos, que es lo que haremos en la clase.

TablaDel3 Escríbelo tú
Proceso TablaDel3
    Definir i Como Entero;
    Para i <- 1 Hasta 10 Hacer
        Escribir "3 x ", i, " = ", 3 * i;
    FinPara
FinProceso
Lo que debe aparecer en la consola (primeras líneas)3 x 1 = 3 3 x 2 = 6 3 x 3 = 9 ...

Ejecútalo y responde:

La última línea que se muestra es 3 x 10 =
¿Cuántas veces se ejecutó el Escribir de adentro del ciclo?
Si cambias Hasta 10 por Hasta 25, el Escribir se ejecutará: veces

La variable i va tomando los valores 1, 2, 3… hasta llegar al límite, y en cada vuelta se repite lo que está entre Hacer y FinPara. Si el límite es n, el trabajo se repite n veces. Esa idea es la base de la clase de hoy.

Consejo de Mixtle

Cada Para necesita su FinPara, y cada Si su FinSi. Si algo no corre, revisa que cada palabra de apertura tenga su cierre.

Suma acumulada

Tu misión: escribe tú mismo un programa que pida un número n y muestre la suma 1 + 2 + 3 + … + n. Intenta primero sin ayuda; si te atoras, abre las pistas.

Pista 1: qué variables necesitas
Necesitas tres variables enteras: n (hasta dónde sumar), i (el contador del ciclo) y suma (donde vas acumulando). Antes del ciclo, la suma debe empezar en cero: suma <- 0;
Pista 2: qué va dentro del ciclo
Un ciclo Para i <- 1 Hasta n Hacer y, en cada vuelta, sumar i a lo que ya llevas: suma <- suma + i;

La variable suma es un acumulador: en cada vuelta guarda lo que tenía más el nuevo valor de i (1, 3, 6, 10…). Llevar una tabla de seguimiento, como la que acabas de llenar, se llama prueba de escritorio y es la mejor forma de revisar la lógica antes de ejecutar.

Ver una solución posible (solo después de intentarlo) 
Proceso SumaAcumulada
    Definir n, i, suma Como Entero;
    Escribir "¿Hasta qué número quieres sumar?";
    Leer n;
    suma <- 0;
    Para i <- 1 Hasta n Hacer
        suma <- suma + i;
    FinPara
    Escribir "La suma es: ", suma;
FinProceso
Para tener a la mano

Cómo corregir los errores más comunes

Lo que pasóQué revisar
PSeInt marca error en una líneaFalta el ; al final o hay un símbolo mal escrito.
El mensaje sale cortado o da error de textoFalta cerrar las comillas: debe haber una " al inicio y otra al final.
El programa no termina de leerseFalta una palabra de cierre: FinProceso, FinPara o FinSi.
El resultado no es el esperadoRevisa el símbolo: <- guarda, = compara, > y >= no son lo mismo.
La variable no existeRevisa que el nombre esté escrito igual en todas partes, sin espacios ni acentos (por ejemplo calificacion).

Conclusión

En esta práctica escribiste tus primeros programas en PSeInt Web y repasaste lo esencial: mostrar mensajes con Escribir, guardar datos con la flecha <-, pedirlos con Leer, calcular con operadores, decidir con Si y repetir con Para. También practicaste ubicar en el teclado los símbolos que más vas a usar. En la clase de hoy aprovecharemos justo lo último: con un ciclo y un contador podremos medir cuántos pasos da un programa, que es la base de la complejidad temporal y espacial.
